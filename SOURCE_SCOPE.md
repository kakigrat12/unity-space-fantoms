# Source scope

This repository contains the 31 authored C# files from `Assets/_Scripts`, plus the original Unity editor version and package manifest.

## Included

- custom character-controller components and input abstractions
- procedural room-spawning code
- bootstrap and installation code
- `ProjectSettings/ProjectVersion.txt`
- `Packages/manifest.json`

## Intentionally excluded

- scenes, prefabs, art, audio, settings assets, and Unity `.meta` files
- generated folders, builds, caches, logs, and IDE metadata
- third-party source and binaries, including Reflex, Odin Inspector, Graphy, and Console Pro

This repository is intended for code review and is not a standalone playable build. The authored source references Unity APIs and external packages including Reflex, Odin Inspector, Cinemachine, Addressables, and the Input System.
